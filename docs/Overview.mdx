We use Lean to understand how agents call each other's services and pay for them.

## Notes

[One paid call](../GiveAndTake/PaidCall/Note.mdx): reservation, settlement,
refund, and conservation of funds.

## Run the example

With [Lean and Lake installed](https://lean-lang.org/install/):

```sh
git clone https://github.com/CloK-Lab/give-and-take.git
cd give-and-take
lake build
lake exe demo
```

The build checks the definitions, examples, and proofs. The demo runs settlement
and refund from the same initial balances.
