These are working notes on how superintelligence and on-chain economic
mechanisms coordinate work and allocate physical and computational resources.

We develop formal models, specifications, and executable code natively in
[Lean 4](https://lean-lang.org/). The current examples cover ledger transfers,
spending authorization, and payment retries. External protocols provide
reference designs for these studies.

## Preliminaries

The preliminaries review reference protocols and define the objects used by
the executable examples.

- [Modules and interactions](../GiveAndTake/Cases/PaidTask/System/Note.mdx): an overview of the
  environment and the relationships between its parts.
- [Quantities and units](../GiveAndTake/Foundation/Quantities/Note.mdx):
  shared definitions for energy, time, asset amounts, nonces, and gas fees.
- [Blockchain infrastructure](../GiveAndTake/Reference/Ethereum/Note.mdx): Bitcoin, Ethereum,
  and Solana: ledger state, transactions, account access, and fees.
- [Assets and tokens](../GiveAndTake/Reference/ERC20/Note.mdx): stablecoins for
  pricing and payments, asset identity, and token balances and transfers.
- [Wallets and authorization](../GiveAndTake/Native/Wallet/Note.mdx): PASS's wallet
  model and a concrete spending policy.
- [Payment protocols and infrastructure](../GiveAndTake/Reference/X402/Note.mdx):
  x402 payment exchange, AP2 authorization, Circle Gateway settlement, and
  Nevermined metering and billing.
- [Agent communication](../GiveAndTake/Reference/A2A/Note.mdx): Agent Cards, skills,
  interfaces, and task states.

## Examples

- [A paid task](../GiveAndTake/Cases/PaidTask/Note.mdx): authorize a payment of 0.003 ETH,
  update balances in wei, and return an echo result.
- [One paid call](../GiveAndTake/Cases/PaidCall/Note.mdx): reservation, settlement,
  refund, conservation of funds, and recovery from a lost reply without a second payment.

## Run the example

[Install the toolchain](https://lean-lang.org/install/), then run:

```sh
git clone https://github.com/CloK-Lab/give-and-take.git
cd give-and-take
lake build
lake exe demo
```

The build checks the definitions, examples, and proofs. The demo runs a
reservation with settlement or refund, a lost reply followed by a retry,
and a payment followed by an echo task.
