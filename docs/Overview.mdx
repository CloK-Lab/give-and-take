These are working notes on how superintelligence and on-chain economic
mechanisms coordinate work and allocate physical and computational resources.

We follow the ecosystem and build as we learn, developing formal models,
specifications, and executable code natively in [Lean 4](https://lean-lang.org/).

## Preliminaries

In the preliminaries, we document the existing infrastructure landscape.

- [Modules and interactions](../GiveAndTake/System/Note.mdx): an overview of the
  environment and the relationships between its parts.
- [Quantities and units](../GiveAndTake/Preliminaries/Quantities/Note.mdx):
  shared definitions for energy, time, asset amounts, nonces, and gas fees.
- [Blockchain infrastructure](../GiveAndTake/Preliminaries/Ethereum/Note.mdx): Bitcoin, Ethereum,
  and Solana: ledger state, transactions, account access, and fees.
- [Assets and tokens](../GiveAndTake/Preliminaries/ERC20/Note.mdx): stablecoins for
  pricing and payments, asset identity, and token balances and transfers.
- [Wallets and authorization](../GiveAndTake/Preliminaries/Wallet/Note.mdx): PASS's wallet
  model and a concrete spending policy.
- [Payment protocols](../GiveAndTake/Preliminaries/X402/Note.mdx): payment options,
  asset amounts, and the distinction between authorization and settlement.
- [Agent communication](../GiveAndTake/Preliminaries/A2A/Note.mdx): Agent Cards, skills,
  interfaces, and task states.

## Examples

- [A paid task](../GiveAndTake/PaidTask/Note.mdx): authorize a payment of 0.003 ETH,
  update balances in wei, and return an echo result.
- [One paid call](../GiveAndTake/PaidCall/Note.mdx): reservation, settlement,
  refund, and conservation of funds.

## Run the example

[Install the toolchain](https://lean-lang.org/install/), then run:

```sh
git clone https://github.com/CloK-Lab/give-and-take.git
cd give-and-take
lake build
lake exe demo
```

The build checks the definitions, examples, and proofs. The demo runs both a
reservation with settlement or refund, and a payment followed by an echo task.
