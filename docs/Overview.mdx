We study decentralized agent economies through formal models, specifications,
and executable code in [Lean4](https://lean-lang.org/) natively.

Here, **decentralized superintelligence (DSI)** describes a proposed network
where humans and SI agents combine their abilities to solve problems beyond
any single participant. Energy powers computation; on-chain payments and
incentives coordinate work and resource allocation, with verification focused on
authorization, accounting, and allocation rules. The goal is to improve
hardware, compute, software, and scientific models with formally verified
properties, and use those advances to maintain and improve the network itself.

and accounts, assets and units, spending authority, service payments, and agent
interaction.

- [Modules and interactions](../GiveAndTake/System/Note.mdx): an overview of the
  environment and the relationships between its parts.
- [Quantities and units](../GiveAndTake/Preliminaries/Quantities/Note.mdx):
  shared definitions for energy, time, asset amounts, nonces, and gas fees.
- [Ethereum and ETH](../GiveAndTake/Preliminaries/Ethereum/Note.mdx): Bitcoin and Ethereum whitepapers,
  transactions, shared state, and ETH.
- [ERC-20 tokens](../GiveAndTake/Preliminaries/ERC20/Note.mdx): OpenZeppelin's token
  ledger, units, and transfers.
- [Wallet authority](../GiveAndTake/Preliminaries/Wallet/Note.mdx): PASS's wallet

- [x402 payments](../GiveAndTake/Preliminaries/X402/Note.mdx): payment options,
  asset amounts, and the distinction between authorization and settlement.
- [A2A interfaces](../GiveAndTake/Preliminaries/A2A/Note.mdx): Agent Cards, skills,
  interfaces, and task states.

## Run the example

[Install the toolchain](https://lean-lang.org/install/), then run:

```sh
git clone https://github.com/CloK-Lab/give-and-take.git
cd give-and-take
lake build
lake exe demo
```

The build checks the definitions, examples, and proofs. The demo runs both a
reservation with settlement or refund, and a payment followed by an echo task.
