Give and Take is a [CloK](https://www.clok.tech/about) learning project. We use
Lean to understand how agents call each other's services and pay for them.

We work through one small question at a time: describe it in ordinary language,
build a formal model and specification, then run the model and examine its
properties. Each note should explain the choices behind the code.

## Start here

[One paid call](../GiveAndTake/PaidCall/Note.mdx) asks what happens to the money
between requesting a service and paying its provider. Starting with a payment of
30 units, we follow reservation, settlement, and refund, then express the rule
that none of these steps should create or lose funds.

This is our first study. It uses a local ledger, so we can understand the
accounting before bringing in a network or blockchain. Further protocol topics
will be added as we work through them.

## Run the example

With [Lean and Lake installed](https://lean-lang.org/install/):

```sh
git clone https://github.com/CloK-Lab/give-and-take.git
cd give-and-take
lake build
lake exe demo
```

The project pins its Lean version. The build checks the definitions, examples,
and proofs; the demo runs the settlement and refund paths from the note.
