This section introduces the basic components of an agent service market:
blockchains, tokens, wallets, payment protocols, and communication and
coordination between agents.

The system consists of five main modules: Ledger, Wallet, Payment, Agent, and Task.

![Module interaction: Agent A requests a task from Agent B and asks its wallet to approve spending. Payment combines the provider's terms with wallet authorization, settles the value transfer in the ledger, and enables task execution. The provider returns the result to Agent A. Asset and Amount identify the transferred quantity.](../../docs/assets/native-system.svg)

The diagram shows one payment-before-execution flow between these modules.
`Ledger` represents local settlement state.

[Quantities and units](../Preliminaries/Quantities/Note.mdx) defines the energy,
time, amounts, and fees used to describe resource consumption and payments
across this environment.

## Infrastructure references

We use these projects as references for the components in the diagram:

- **Ledger:** [Ethereum execution-specs](https://github.com/ethereum/execution-specs)
  for account state and transaction execution;
  [Solana and Agave](https://github.com/anza-xyz/agave) for program-owned accounts
  and access conflicts. Bitcoin supplies the UTXO and payment-history reference.
  [Study notes](../Preliminaries/Ethereum/Note.mdx).
- **Asset and Amount:** [OpenZeppelin Contracts](https://github.com/OpenZeppelin/openzeppelin-contracts)
  for ERC-20 balances, units, and transfers;
  [USDC](https://developers.circle.com/stablecoins/what-is-usdc) for stablecoin
  pricing, payments, and the role of reserves and redemption.
  [Study notes](../Preliminaries/ERC20/Note.mdx).
- **Wallet:** [PASS's wallet model](https://github.com/pass-wallet/pass-lean4-proofs)
  for wallet accounts and transaction processing.
  [Study notes](../Preliminaries/Wallet/Note.mdx).
- **Payment:** [x402](https://github.com/x402-foundation/x402)
  for payment requirements, verification, and settlement.
  [Study notes](../Preliminaries/X402/Note.mdx).
- **Agent and Task:** [A2A](https://github.com/a2aproject/A2A)
  for capability discovery, messages, and task states.
  [Study notes](../Preliminaries/A2A/Note.mdx).
